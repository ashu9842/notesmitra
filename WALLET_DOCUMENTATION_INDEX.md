## 💡 Key Concepts

**Available Balance**: Money that can be withdrawn after accounting for pending withdrawals
```
Formula: availableBalance = MAX(0, balance - pendingWithdrawals)
```

**Pending Withdrawals**: Funds reserved for withdrawal requests awaiting admin approval
- Immediately deducted from balance
- Deducted from available balance until approved
- Add to available balance once approved

**Completed Withdrawals**: Successfully transferred funds
- Not part of current balance (already deducted)
- Tracked separately for audit trail
- Do not affect available balance

**Platform Wallet**: Now same as seller wallet
- Tracks commission balance
- Tracks available commission
- Can request withdrawals
